# Node Express Task Manager

## Overview
A simple task manager web application built with Node.js, Express, EJS, and SQLite.

## Features
- Create tasks
- View tasks
- Edit tasks
- Delete tasks
- Title validation
- Persistent storage with SQLite

## Tech Stack
- Node.js
- Express
- EJS
- SQLite
- HTML
- CSS
- JavaScript

## Run Locally
```bash
npm install
npm run dev
